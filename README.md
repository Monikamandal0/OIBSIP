# Number Guessing Game

## About the Project

Number Guessing Game is a simple Java console game where the computer generates
a random number between 1 and 100, and the player tries to guess it within a
limited number of attempts.

The game also allows the player to play multiple rounds and keeps track of
the score.

## Features

- Random number generation between 1 and 100
- Maximum of 10 attempts per round
- "Too High" and "Too Low" hints
- Correct guess detection
- Attempt counter
- Score tracking
- Multiple rounds
- Play Again option
- Input validation
- Handles invalid and out-of-range input

## Technologies Used

- Java
- Scanner
- Random
- VS Code
